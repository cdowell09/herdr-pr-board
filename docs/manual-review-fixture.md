# Manual review fixture

This file supplies a small documentation change for PR Board testing.

Use this PR to check these results:

- The board displays the open PR.
- Repository setup saves the selected reviewer.
- A manual review records a local outcome.
- A second review request recognizes the completed revision.
- An explicit rerun creates another review attempt.
- Publication requires the configured action permission.

Use a new commit to test review eligibility for a changed revision.
