PR Board now manages agent reviews alongside your pull requests, from launch to findings and optional GitHub publication.

### Highlights

- **Run reviews from the board.** Use the built-in Pi adapter or a custom reviewer command. Inspect findings and revision history without leaving Herdr.
- **Review automatically in the background.** Select views and enable each repository. A shared monitor keeps reviews running after you close the board.
- **See review progress at a glance.** The new **REV** column uses the same status symbols as CI. **POSTED** distinguishes GitHub reviews, PR Board reviews, and both sources. Selected details identify current and older revisions.
- **Control each repository.** Choose its reviewer and review skill profile. Set shared review concurrency and timeout. Keep findings local or enable permitted GitHub publication.
- **Use the same data outside the UI.** Headless monitoring and versioned JSON snapshots expose PR metadata, CI, submitted reviews, and retrieval errors.

Automatic reviews and GitHub publication require explicit configuration.
See [review setup](https://github.com/cdowell09/herdr-pr-board/blob/v0.4.0/docs/reviews.md) and [automatic reviews](https://github.com/cdowell09/herdr-pr-board/blob/v0.4.0/docs/automatic-reviews.md).

### Upgrade

```sh
herdr plugin install cdowell09/herdr-pr-board --ref v0.4.0
```

Existing configuration and runtime state remain available.
Reopen the board to load the new binary.
Restart an older monitor after its active reviews finish.
