PR Board opens in the workspace that you view and keeps your settings edits safe.

### Highlights

- Open the board from any workspace. The open action moves a board from another workspace to a new tab in your workspace.
- Keep one board. The action starts a new board only when Herdr confirms that the old board is gone.
- See sidebar counts where the board runs. After a move, the counts follow the board and leave the old workspace.
- Keep every settings edit. Two saves to the same configuration file can no longer replace each other.

See [board controls and status](https://github.com/cdowell09/herdr-pr-board/blob/v0.9.1/docs/board.md) for the open action.

### Upgrade

```sh
herdr plugin install cdowell09/herdr-pr-board --ref v0.9.1
```

Reopen the board to load the new binary.
