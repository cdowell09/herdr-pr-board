PR Board shows the selected PR's local reviews under the table, so you act without leaving the board.

### Highlights

- Read the review region under the PR table. It shows the posted reviews, the latest run, its findings, the automation state, and the details.
- Press `v` to zoom the region to the full height and see every run. Press `v` or `Esc` to return. A terminal under 24 rows shows a one-line summary and still zooms.
- Run, stop, publish, and configure reviews from the board. The keys `n`, `N`, `t`, `s`, `c`, `a`, and `x` work on the board and in zoom.
- Scroll the region with `j`, `k`, `g`, `G`, `PgUp`, `PgDn`, or the mouse wheel. The arrow keys, `Home`, and `End` still select PRs.
- One local read per second feeds the REVIEW column and the region, so the two never disagree. Selecting another PR binds the region at once.

See [use the review region](https://github.com/cdowell09/herdr-pr-board/blob/v0.8.0/docs/reviews.md#use-the-review-region) for the layout, the keys, and the footer.

### Upgrade

```sh
herdr plugin install cdowell09/herdr-pr-board --ref v0.8.0
```

Reopen the board to load the new binary.
Restart an older monitor after its active reviews finish.
